# Healthy Faith Study downloads

Installers for **Healthy Faith Study**, the free desktop Bible study app from Hardaway Labs.

- Mac: https://www.healthyfaithdaily.com/download
- Windows: [Microsoft Store](https://apps.microsoft.com/detail/9NBRM8BNFCKN)

This repository only hosts the signed, Apple-notarized Mac installers. Support: https://www.healthyfaithdaily.com/support
